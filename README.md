# Macsellas Ventures LLC website

Five-page static website for local preview and editing.

## Preview

Open `index.html` in a browser. Use the navigation to visit About, Automotive Services, Digital & Creative Services, and Media Consulting / Contact.

## Files

- `index.html`, `about.html`, `automotive.html`, `digital.html`, `media-contact.html` — page content
- `assets/site.css` — shared visual styles and responsive layouts
- `assets/site.js` — mobile menu, current year, and inquiry form service preselection

## Before launch

- Replace `REPLACE-WITH-YOUR-EMAIL@example.com` in `media-contact.html` with the business email.
- The inquiry form currently opens the visitor’s email application. Connect a form handling service or backend for direct online submissions.
- The supplied logo is included as a transparent PNG at `assets/macsellas-logo-transparent.png` and used in the site header and footer.
- Google Fonts are loaded from Google Fonts when internet access is available; system sans-serif fallbacks are included.

Automotive service copy describes coordination only and notes that auction access, sales, repairs, and transport depend on applicable licensing and qualified providers.
